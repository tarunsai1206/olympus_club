# AURA | High-End Luxury Fitness & Wellness Website

A production-ready, ultra-luxurious gym and fitness sanctuary landing page template designed with a modern dark aesthetic, gold accents, and a clean glassmorphism UI. 

Built from scratch using native web technologies for maximum performance and zero bloatware.

##  Key Features
* **Glassmorphism UI & Dark Aesthetics:** Sophisticated design language crafted with Obsidian Black, Brushed Gold accents, and backdrop blur effects.
* **Interactive Biometric Calculator:** Built-in vanilla ES6 JavaScript BMI calculator that instantly evaluates body composition and athletic baselines.
* **Fully Responsive Layout:** Fluid grid system optimized for desktop, tablet, and mobile viewing with a smooth hamburger navigation toggle.
* **Performance First:** Zero heavy CSS/JS frameworks or external libraries—pure vanilla code for instant load times.

##  Built With
* **HTML5** (Semantic markup)
* **CSS3** (Custom properties, Flexbox, CSS Grid)
* **JavaScript (ES6+)** (DOM manipulation and interactive UI logic)
